# 视觉自审清单（执行智能体 + 视觉模型强制过）

每套模板、每次改编辑器 chrome、每次改落地页/仪表盘/更新条，都要过本清单。失败 = 该任务没完。

用视觉模型看**整页**，不是看组件代码。对照物：国内能投智联/BOSS/官网网申的附件简历（超级简历「通用/校招」那种），不是 Canva、不是 LinkedIn Creative。

---

## A. 纸面（A4 简历）

渲染 4 份数据再看：

1. 应届生：姓名中文、求职意向「前端开发实习生」、有证件照、教育在前、项目 2 条、技能分组文字
2. 社招：工作 2 段在前、无照片
3. 体制内（若该模板宣称支持）：矩形证件照、政治面貌等自定义字段
4. 几乎空：只填姓名电话，其它模块空

### 必须像

- [ ] A4 竖版，信息密，不是海报
- [ ] 头部：姓名最大；求职意向次之；电话/邮箱/城市/微信一行或两行，用 `·` 或 `|`，**不要**一堆彩色 Lucide 图标当正文
- [ ] 有照片时：右上角，**证件照比例约 5:7 矩形**（互联网模板允许轻微圆角 ≤4px）。体制内禁止圆形大头像
- [ ] 分节：左色条或底边线或浅底标题，中文「教育背景 / 工作经历 / 项目经历 / 专业技能 / 校园经历 / 荣誉奖项 / 自我评价」
- [ ] 主题色只用在标题线/少量强调，正文近黑 `#222`/`#333`，纸白
- [ ] 页边距看起来 12–20mm，没有「纸中间浮着一张小卡片」
- [ ] 技能是分类文字或简单 tag，**不是**百分条、雷达图、星级
- [ ] 空模块完全没有标题、没有空白洞
- [ ] 中文标题没有被 `letter-spacing` 拉成「教  育  背  景」

### 一票否决（出现即打回）

- [ ] 技能条 / 「2 份工作 1 个项目」统计卡
- [ ] 垂直时间线圆点 + 轨道占掉一列
- [ ] 左侧 30% 满屏色块 + 英文 Contact
- [ ] 渐变波浪、clip-path、紫粉渐变头部
- [ ] 英文全大写栏目（SUMMARY、WORK EXPERIENCE）出现在**中文**模板（`enSimple` 允许英文栏目标题，仍禁止 infographic）
- [ ] 大段留白、姓名居中像请柬
- [ ] 强制「致谢」「感谢您花时间阅读」页脚
- [ ] 照片圆形且很大、生活照滤镜感
- [ ] 双栏色条四周一圈白边（全局 padding 没拆掉）
- [ ] 视口变窄后纸面上的照片或日期栏消失（说明用了 `md:`/`sm:`）

### 分页

- [ ] 第二页不是半截色条
- [ ] 标题不孤行在页底
- [ ] 校招示例优先一页；超页有编辑器提示，不是静默切肉

---

## B. 编辑器 chrome（软件界面）

- [ ] 左表单右 A4，像超级简历/国内效率工具
- [ ] 不要大紫渐变、不要大 Framer 入场、不要英文 placeholder 堆砌
- [ ] 顶栏：简历名、保存状态（真的）、模板、样式、导出、更新
- [ ] 保存失败是红/警告，不是永远「已保存」
- [ ] 撤销/重做按钮看得到（不要只靠被抢走的 Ctrl+Z）
- [ ] 模板选择：6～8 张**静态或低成本缩略图**，不要同时挂载 35 份真 A4
- [ ] 触摸屏：卡片操作（删除/复制）始终可及，不要纯 hover

### 落地页 / 仪表盘

- [ ] 中文、说人话：免费、本地、模板正常、能导出、能更新
- [ ] 不要写「35+ 精美模板」如果实际已收到 8 套
- [ ] 仪表盘缩略图可认作对应模板，不要全是李明演示脸

---

## C. 桌面窗口

- [ ] 打开就是工具，不是先看英文欢迎
- [ ] 更新条：有新版本、下载进度、立即更新，中文
- [ ] 菜单栏隐藏可以，但别让用户以为程序没响应（`show: false` 必须 ready-to-show 或超时显示错误）

---

## D. 导出件

打开生成的 PDF/PNG/Word（或预览栅格）再看：

- [ ] PDF 页边、字体、照片与屏幕预览同一构图
- [ ] 桌面 PDF 文字能选中、能复制（若走 printToPDF）
- [ ] 浏览器降级方案若仍是截图，必须在 UI 标明「图片型 PDF，网申请优先 Word」
- [ ] Word 打开是正经简历结构，不是一坨无标题正文
- [ ] 文件名：`姓名_求职意向_简历.pdf`，无 `\ / : * ? " < > |`

---

## E. 自审记录格式

每过一次，在 `开发方案/执行记录.md` 追加：

```
### 视觉自审 YYYY-MM-DD 模板/页面名
- 截图：开发方案/research/visual/<id>-<应届|社招|空>.png（无路径 = 未做）
- 数据：应届/社招/空
- 结论：通过 / 打回
- 打回原因：（具体：哪一块空白、哪条技能条、哪句英文）
- 视觉模型看到的问题：
```

连续打回两次仍怪：停下来对照 `research/02-竞品审美` 再改，不要再叠特效。
