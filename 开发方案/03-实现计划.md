# ResumeX 实现计划

> **For agentic workers:** 先读 `00-执行总提示词.md`。阶段 0 必须 `spawn_subagent`。UI 必须走 `05-视觉自审清单.md`。

**Goal:** 把 ResumeX 做成可流畅使用的国内简历桌面软件，含 GitHub 自动更新。

**Architecture:** 继续 React SPA + Zustand；存储迁 IndexedDB；模板改为共享原语上的 6～8 套国内版式；Electron 加 preload/IPC/electron-updater；构建产物无空格文件名 + latest.yml。

**Tech Stack:** 现有 React 18、Vite、Tailwind 4、Zustand、HashRouter、Electron 33、electron-builder 25；新增 `idb-keyval`、`electron-updater`（dependencies）。

## Global Constraints

- npm 在 `界面/`；根目录只跑 Electron 构建
- 代码/注释中文
- 模板禁用视口断点；禁用全局 `!important` 垫 padding
- 不新增后端
- 不把西方 infographic 加回默认列表
- persist 失败必须可见；禁止李明覆盖损坏数据
- 安装包文件名无空格
- 每个阶段结束：相关测试绿 + 该阶段视觉/功能验收
