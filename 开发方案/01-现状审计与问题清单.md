# 现状审计与问题清单（已核实，禁止当未知重探）

审计对象：本地仓库 `ResumeX`（与 https://github.com/Jovan1666/ResumeX `main` 一致）。11 个 commit。GitHub 有 `v1.0.0` 安装包，无 Issue。

本文只记录**代码里能指到文件的问题**。审美细节的最终数字由执行阶段子智能体调研锁定，但「像西方花简历」这个判断已经成立。

---

## 产品形态

这不是带后端的全栈项目。纯前端 SPA（React 18 + TS + Vite + Tailwind 4 + Zustand）+ 很薄的 Electron。数据在浏览器存储。

同时存在三条互不相通的启动路径：

| 路径 | 文件 | 实际 | 文档怎么说 |
|---|---|---|---|
| 一键启动 | `启动.bat` → `start.js` | 本机 Vite `npm run dev`，必须 Node 18+ | README 主推 |
| 便携 zip | `build-release.js` | 零依赖 `server.js` 端口 5678 | 代码有，GitHub **没发** |
| 安装包 | `build-setup.js` + `electron/` | NSIS `ResumeX Setup 1.0.0.exe` | GitHub Release 有，README **没写** |

用户「没法流畅用」很大程度来自：按文档要装 Node、等 npm；装了 exe 仍是同一套有病的编辑器；仓库更新了软件无感知。

## P0 数据丢失 / 保存是假的

### P0-1 localStorage 配额 + 「已保存」谎言
- 文件：`界面/src/app/store/useResumeStore.ts` persist `name: 'resume-storage'`，无写入失败处理
- `界面/src/app/components/editor/EditorLayout.tsx`：`isSaving` 只是 300ms 计时；Ctrl+S 只 toast「简历已保存」
- 头像是 base64 进整库。`BasicInfoForm` 允许 5MB 原图。超配额后 persist 失败，UI 仍显示已保存

### P0-2 损坏的 `resume-storage` 会被演示数据覆盖
- `onRehydrateStorage` 在解析失败/空 state 时，内存回到 `initialResumeData`（李明）
- 下一次 persist 把损坏 key 写成演示简历，用户数据没了
- 无 `version` / `migrate`

### P0-3 导入备份竞态
- `界面/src/app/utils/backup.ts`：写入 localStorage 后 500ms `reload`
- 这 500ms 里 Zustand 仍是旧 state，任意 persist 会冲掉刚导入的文件

### P0-4 基本信息卸载不 flush
- `ValidatedInput.tsx` cleanup 只 `clearTimeout`，不把最后一次输入写入 store
- 折叠「基本信息」或快速离开，最后几百毫秒字丢了
- `DebouncedInput.tsx` 卸载会 flush，两边行为不一致

## P1 撤销与输入（「根本没法流畅用」的主因）

### P1-1 第一次 Ctrl+Z 经常没反应
- `UndoRedoManager.push` 推的是**改完后**的快照
- `EditorLayout` 对 `deferredResumeData` 1s debounce 调 `pushHistory`
- undo 弹出的是当前状态的克隆，写回去等于没撤

### P1-2 撤销后 2 秒输入不进历史
- `useResumeStore.ts`：`_skipHistoryUntil = now + 2000`
- 为了避开 debounce 污染，连用户新输入也跳过；再 undo 这些字一起没

### P1-3 全局抢走输入框 Ctrl+Z
- `EditorLayout.tsx` `keydown` 对所有 Ctrl+Z `preventDefault`
- 改错字撤销变成整份简历倒回
- 无撤销按钮；手机等于没有撤销

### P1-4 防抖回声覆盖正在输入的字
- `ValidatedInput` / `DebouncedInput`：外部 `value` 一变（含自己的 debounce 写回）就 `setLocalValue(external)` 并取消 pending timer
- 停 300ms 再连打，多打的字可能被弹回

### P1-5 DatePicker 「至今」卡住
- `DatePicker.tsx`：`isPresent` 在 `value === '至今'` 时置 true，value 变成日期后不清空
- 显示「至今」，store 已是 `2023.06`

### P1-6 手机号校验与演示数据冲突
- `useFormValidation.ts`：`/^1[3-9]\d{9}$/`
- `initialData.ts`：`"138 0000 0000"`（有空格）
- 失焦即红字。清单里会去空格，表单不会

### P1-7 微信 / 自定义字段表单缺失
- 类型有 `profile.wechat`、`profile.customFields`
- `BasicInfoForm` 「个人网站 / 微信」只写 `website`
- 多套模板渲染 wechat/customFields，用户填不了 → 预览缺块

### P1-8 切模板不切主题
- `TemplateModal.tsx` `templateThemeMap` 只给缩略图用
- 确定时只 `setTemplate`，科技橙红还在

### P1-9 仪表盘删除/复制仅 hover
- `Dashboard.tsx` `opacity-0 group-hover:opacity-100`
- 触摸屏删不掉

### P1-10 Tech 模板照片 `hidden md:block`
- `TechTemplate.tsx`（默认模板）
- Tailwind `md` 是**视口**不是 A4。窄窗/移动导出 PDF 没照片
- `VibrantTemplate` 同样用了 `sm:`

### P1-11 HashRouter 下 `href="/"`
- `App.tsx` 404、`ErrorBoundary.tsx`
- Electron `loadFile` 会跳到 `file:///` 空白，不是 `#/`

### P1-12 新简历克隆李明
- `addResume` / `addResumeFromPreset` 深拷贝 `initialResumeData`
- 落地页「开始」也容易导出假简历

## 导出

### E-1 PDF 是整页 JPEG
- `EditorLayout.handleExportPdf`：`html-to-image` `toCanvas` + jsPDF `addImage` 负 y 切片
- 文字不可选、文件大、从句子中间切开、双栏第二页色条空心
- 成功 toast 即使 `MAX_PAGES=20` 截断

### E-2 PNG 同样截 DOM
- 父级 zoom transform 要临时摘掉，失败路径有漏恢复风险（finally 里有恢复）

### E-3 Word 是另一套纯文本
- `exportDocx.ts` 不复刻模板。头像 60×60。用户以为所见即所得

### E-4 打印 CSS 的 class 模板没用
- `print.css` 写了 `.module-section` / `.experience-item` `break-inside: avoid`
- 模板组件没有这些 class

### E-5 Google Fonts
- `界面/index.html` 拉 `fonts.googleapis.com`，国内常挂
- 导出用本地 YaHei 映射，预览和 PDF 字体不一致

## 模板（畸形的根因）

35 套在 `界面/src/app/components/templates/`。默认 `template: 'tech'`。

### T-1 全局 padding 叠加（最大视觉 bug）
`界面/src/styles/fonts.css`：

```css
.resume-page[data-margin="standard"] > div {
  padding: 14mm 20mm !important;
}
```

模板自己还有 `p-6` / `px-6`。实际边距 ≈ 20mm+24px。国内常见约 10–20mm。双栏色条被白框包一圈，像 Canva 图贴在纸上。

### T-2 数据模型不是国内栏目
`ModuleType = experience | education | projects | skills | custom`
没有一等公民：校园经历、荣誉奖项、自我评价（评价在 `profile.summary`，有的模板放最后、有的当获奖）。
默认顺序：工作 → 项目 → 教育（校招应教育在前）。`quickStartPresets.ts` 应届生其实已经教育优先，但默认 `addResume` 不是。

### T-3 空模块仍占标题
只 `filter(m => m.visible)`，`items: []` 照打彩色标题。

### T-4 假技能条
`InfographicTemplate` 等：`item.level || (90 - index * 8)`

### T-5 英文/西式
Professional：`Contact` / `Profile`；Academic 双语大写；大量 `uppercase tracking-widest` 作用在中文标题上（字距拉成畸形）。

### T-6 行业模板错映射
Accountant/HR：skills 当成「奖励荣誉」；Engineer 写死假标签；Operations 把 `location` 标成「负责业务」；JavaDev 用 `profile.title` 当 H1（职位看起来像姓名）。

### T-7 相对能看、应作为改造起点的
`eduDark`、`recruitBk`、`generalRed`、`civilService`（证件照矩形）、`civilGray`（但强制「致谢」应删）。

### T-8 必须移出默认的
infographic、creative、executive、timeline、professional（美式双栏+英文）、card、vibrant、以及会计/人事/医疗/教师那种 30% 大色块侧栏。

### T-9 模板选择器卡顿
`TemplateModal` 对 35 套各渲染完整 A4（还是李明、无头像）。

## Electron / 更新

`electron/main.js`：单窗口、`loadFile(../webapp/index.html)`、无 preload、无 IPC、无 autoUpdater。
`package.json`：`appId com.resumex.app`，NSIS per-user，**无** `repository` / `publish` / `electron-updater` 依赖。
`build-setup.js`：构建完**删除** `webapp/`，直接 `electron .` 会空白。
GitHub `v1.0.0` 资产：`ResumeX.Setup.1.0.0.exe`（点号），本地产物名带空格；**无 `latest.yml`**。
未签名 → SmartScreen 会拦，更新仍可做，体验差。

其它：窗口 `show: false` 且无 `did-fail-load`；未 `setAppUserModelId`；ICO 生成脚本写了 512 尺寸（ICO 单字节宽高，256 以上非法）。
