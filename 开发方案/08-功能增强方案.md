# ResumeX 功能增强方案（基于 07 吸收清单，全部原创实现）

> 本方案把 `research/07-开源竞品吸收清单.md` 的设计理念转成具体改动。
> **原则**：只吸收设计理念 → 用我们自己的 schema / 命名 / 组件 / 文案实现。
> 代码中不出现任何开源项目的字段名、类名、组件名、文案。

## 目标（按优先级）

### 第一优先：模板与排版增强（用户体验大头）

1. **模块级设置原子化**：每个模块支持
   - 显示/隐藏（已有 `visible`）→ 维持
   - **标题文案可改**（新增 `settings` 存模块自定义标题）
   - **标题样式三选一**：下划线 / 左侧色条 / 纯加粗无装饰（新增 `titleStyle`）
   - **项目符号 on/off**（新增 `bulletStyle`：圆点 / 破折号 / 无）
   - **列数**：1 列 / 2 列（教育背景、技能常用两列）
2. **双栏模板参数化**：`compactSplit` 支持
   - 左栏宽度三档（25% / 30% / 35%）
   - 左栏底色（浅灰 #FAFAFA / 浅蓝 #EFF4FB / 白 #FFFFFF）
3. **照片控件**（新弹层）：
   - 位置：右上 / 顶部居中 / 左栏顶（双栏才有）
   - 形状：矩形（默认）/ 圆角
   - 尺寸：小（20×28mm）/ 中（22×30.8mm 证件照）/ 大（25×35mm 一寸）
   - 宽高比预设：1:1 / 25:35（证件照）/ 自由
4. **ATS 极简模板增强**：`atsMono` 加「文字可选中自检提示」+ 网申推荐 Word 入口
5. **打码模式**：分享/预览时一键隐藏姓名、手机、邮箱、微信（渲染层开关，数据不动）

### 第二优先：编辑器体验

6. **模块管理面板分区**：物料（添加模块）/ 排序（拖拽）/ 配置（样式）三页签
7. **智能推算**：出生年 → 自动计算年龄提示；入职时间 → 工作年限提示
8. **三滑杆**：页边距 / 模块间距 / 行距（全局样式抽屉内）

### 第三优先：导出

9. **导出双出口**：高清版（所见即所得，截图）/ 网申版（文字可选中，仅 ATS 模板；浏览器打印路径）
10. **全局样式抽屉**样式面板按「全局 → 页面 → 区块」分层

## 实现计划（分 3 批）

### 批 1：数据层与类型（先改 schema）
- `resume.ts`：`ResumeModule` 增加 `titleOverride`、`titleStyle`、`bulletStyle`、`columns` 可选字段
- `theme.ts`：`GlobalSettings` 增加 `photoPosition/photoShape/photoSize/photoAspect`、`privacyBlur`、`splitWidth/splitColor`、`moduleGap`
- migrate version 3 补齐新字段默认值（保持兼容）

### 批 2：模板层（8 套模板全部用新设置）
- `_primitives/SectionTitle.tsx`：支持三种样式 + 栏目图标开关
- `_primitives/ExperienceItem.tsx`：支持项目符号开关（bullet 类型切换）
- `_primitives/HeaderBlock.tsx`：支持照片位置/形状/尺寸
- `CompactSplitTemplate.tsx`：双栏宽度/底色参数化
- `AtsMonoTemplate.tsx`：纯文字 + 无装饰标题 + 无照片位默认

### 批 3：编辑器与导出
- `ModuleList/ModuleItem`：标题可编辑 + 样式/项目符号开关 + 列数
- `StyleSettingsPanel`：三滑杆 + 照片控件 + 双栏参数 + 打码开关
- 导出菜单：双出口文案 + 打码模式提示

## 验收
- type-check / test / build / lint 通过
- 每个新设置项在模板上生效（截图验证）
- 打码模式截图：姓名/手机/邮箱打码
- 模块标题自定义在 paper 生效
