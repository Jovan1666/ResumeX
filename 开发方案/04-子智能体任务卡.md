# 子智能体任务卡（执行智能体阶段 0 必须真的 spawn）

规划阶段**没有**把网上材料搜完。执行智能体在写模板、改导出、接更新器之前，必须并行开启下列子智能体。不要用自己的记忆代替。

统一要求：

- 子智能体类型：能 `web_search` / 打开网页的通用智能体（工具名随环境）
- 产出**只写**指定路径，Markdown，每条事实带 URL
- 打不开官网就换镜像/知乎/少数派/官方文档，并注明「未打开官网」。写死的 electron.build URL 若 404，搜索标题「Auto Update electron-builder」
- 禁止把欧美 CV 规范写成国内标准
- 失败：换 query/工具名再开同一张卡，最多 3 轮。**R3/R4 不允许用默认值跳过**（必须有可粘贴配置）。仅 mm/pt/hex 允许采用 `02` 默认值，并写进执行记录

## R1 国内简历版式规范

**产出：** `开发方案/research/01-国内简历版式规范.md`

**必须搜索并打开页面：**

- 校招简历一页纸 教育背景放前面
- 超级简历 校招简历排版 字体 边距（wondercv.com / chaojijianli.com 博客）
- 网申 ATS 简历格式 中国 智联 北森
- 公务员 事业单位 简历 照片 政治面貌
- 简历 页边距 厘米 字号 微软雅黑 宋体
- HR 反感 技能条 花哨模板

**必须回答：**

1. 校招 vs 社招 vs 体制内：栏目顺序、是否照片、几页
2. 页边距 mm、姓名/标题/正文字号 pt、行距、推荐字体
3. 照片：一寸尺寸、位置、圆/方、哪些岗位不要照片
4. 头部字段：年龄/性别/政治面貌/籍贯/微信 哪些场景要
5. 明确禁止的视觉元素列表
6. 给 ResumeX 的栏目数据模型建议

**默认（仅当搜索失败才用）：** A4；边距 15–18mm；姓名 16–18pt；栏目 12–14pt 加粗；正文 10–11pt；行距 1.15–1.35；互联网微软雅黑，体制内宋体/黑体；校招一页且教育在前；照片可选，右上矩形 5:7。

## R3 Electron 自动更新（官方文档优先）

**产出：** `开发方案/research/03-Electron自动更新.md`

**必须打开：**

- https://www.electron.build/docs/features/auto-update
- https://www.electron.build/docs/publish/
- electron-updater README（GitHub electron-userland/electron-builder packages/electron-updater）
- NSIS 目标、artifactName、latest.yml 字段
- GitHub Actions 用 electron-builder `--publish always` 的近期示例

**必须交付可粘贴配置：**

1. 根 `package.json` 的 `build.publish`、`repository`、`artifactName`（无空格）
2. `electron-updater` 必须在 **dependencies** 不是 devDependencies（请用文档确认）
3. Release 资产列表：`exe` + `latest.yml` + 可选 `blockmap`
4. 主进程：`autoDownload: false` + 进度事件 + `quitAndInstall`
5. preload `contextBridge` API 形状
6. 版本从哪读（根 package.json）
7. 未签名能否更新、SmartScreen 会怎样
8. 国内访问 github.com 失败时的降级（提示浏览器打开 Releases 页下载，不要假装更完了）
9. 当前 v1.0.0 没有 latest.yml：新版本如何成为第一条可更新基线（用户需装新底包）

**仓库约束：** Electron 33.2.1，electron-builder 25.1.8，appId `com.resumex.app`，NSIS per-user，repo `Jovan1666/ResumeX`。若官方要求升 builder，记录兼容性，不要默默升到把构建打爆。

## R4 PDF / Word 导出

**产出：** `开发方案/research/04-PDF与Word导出.md`

**必须查：** Electron `webContents.printToPDF` 当前 API（pageSize A4、printBackground、margins）；`window.print` + `@page`；html-to-image 在 `file://` 的坑；docx 库中文/图片。

**必须给出主路径：**

- **Electron：** 优先 Chromium 打印 PDF（文字可选中）
- **浏览器：** 次优 print 或改进截图，并在 UI 诚实标注
- Word：干净国内结构（标题样式、雅黑、矩形证件照），不追求像素级复刻花模板
- PNG：投递截图场景保留
