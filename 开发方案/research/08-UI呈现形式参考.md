# 08 UI 呈现形式参考（前端重做设计依据）

> 调研方式：参考截图 5 张（wondercv/linear/shadcn/reactive-resume/flowcv 实际渲染页面，存于 research/visual/）+ 已知 UI 趋势整理。
> 输出：ResumeX 全站呈现形式的设计依据与 token 建议。

## 参考截图（research/visual/）
- `wondercv-landing.png`：超级简历（国内简历 SaaS）—— 深蓝黑底 + 橙红 CTA + 编辑器截图 + 模板网格 + 数据横幅
- `shadcn-home.png`：shadcn/ui（现代 Web UI 标准）—— 纯白底/黑白主色/卡片网格/圆角/轻阴影
- `linear-home.png`：Linear —— 深底近黑、极简排版、功能点网格
- `reactive-resume-gh.png`：Reactive Resume GitHub —— 开源简历工具仓库页
- `flowcv-landing.png`：FlowCV —— 简历 SaaS 落地页（浅色编辑界面）

## 核心结论

**国内简历工具的呈现形式 = 「前半场像 Super Resume/wondercv（信息密度 + 强 CTA），后半场像 shadcn（白底极简卡片）」**
- 用户看简历工具的第一眼是「编辑器可用性」与「模板丰富度」，不是炫酷动画
- 落地页要有：编辑器截图背书 + 模板网格 + 数据/信任行 + FAQ
- 主色可以保留「蓝」（专业/可信），黑白灰做骨干

## 分页面呈现形式

### 1. 落地页（保留白底系，但密度加大）
- 顶部导航：logo + 我的简历 + 开始制作
- Hero：大标题「免费的中文简历工具」+ 副标题 + 双 CTA（开始/导入）+ 信任行
- **编辑器截图大图**（中间放一张真实编辑器缩略图，比纯模板卡更有说服力）
- 模板网格（4×3，12-14 套缩略图，hover 放大）
- 3 功能点（导出/本地/模板）
- 数据统计条（14 套模板 / 全格式导出 / 100% 本地）—— 可简化
- FAQ（3-4 条常见问题）
- 底部 CTA + Footer

### 2. 仪表盘（白底，卡片网格）
- 顶栏：logo + 导出/导入/设置 + 新建简历
- 主区：空态（立即创建 + 导入备份）或卡片网格（缩略图 + 操作常显）
- 卡片信息：模板中文名 + 最近编辑时间 + 主题色点

### 3. 编辑器（左右分栏 + 右侧抽屉，已做浅色顶栏）
- 左栏 360px：步骤条导航 + 基础信息 + 模块列表
- 中央：A4 预览（缩放工具条）+ 页数指示
- 右侧抽屉：样式设置（字体/字号/行距/页边距/模块间距/照片/双栏/打码）
- 顶栏：白底，返回 + 名称 + 保存状态 | 撤销/重做/样式/模板/导出

## 设计 Token（应用到全站）

| token | 值 |
|---|---|
| 主色 primary | #2563EB（蓝600） |
| 主色 hover | #1D4ED8（蓝700） |
| 背景 | 页面 gray-50 #F9FAFB / 卡片 #FFF / 编辑器预览区 #E8EAED |
| 中性文字 | 标题 #111827 / 正文 #374151 / 次要 #6B7280 / 弱 #9CA3AF |
| 圆角 | 卡片 xl 12px / 按钮 md 8px / 标签 full |
| 阴影 | sm 卡片 / lg 悬浮下拉 / 2xl 弹窗 |
| 字体 | 正文 14px；标题 20px；页面标题 24px；Banner 36px |
| 间距 | 4/8 倍率；卡片 p-6；区块 gap-4 |
