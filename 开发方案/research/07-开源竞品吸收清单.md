# 07 开源竞品吸收清单（调研）

> 目标：调研 GitHub 同类开源简历产品，为 ResumeX（中文简历工具）整理「吸收清单」——**只吸收设计理念 / 功能特性，明确禁止复制任何代码、markup、类名、文案**。
> 方法：GitHub MCP 直接读仓库目录树与关键源码 schema（数据模型、设置项），WebFetch 读 README。每条事实附 URL。
> 范围：重点 3 个（猫步简历、Reactive Resume、open-resume）+ ATS 向（markdown-resume）+ 国内向补充（opresume、dnd-resume）。
> 与 02 号文件分工：02 已调研国内商业站（WonderCV/五百丁/木及/乔布/幻主）的**模板审美**；本文聚焦**开源项目**的模板设计、设置组织、导出机制与产品理念。

## 0. 结论速览（先看这 8 条）

| 主题 | 结论 |
|---|---|
| 模板数量 | 开源项目普遍只做 1（open-resume）~ 15 套（Reactive Resume），套数少、但每套打磨深；国内商业站靠车海战术（3000+） |
| 模板组织 | 两大派：**「布局骨架 X 样式变体」解耦**（Reactive Resume：模板 = 骨架选择 + 布局 main/sidebar 分栏 + 字体/颜色/间距自由调）vs **「成品即模板」**（open-resume/猫步：一模板一档配置） |
| 栏目标题 | 开源英文项目：加粗大写 + 图标（Phosphor）；国内项目（猫步）：文字 + 图标，重「模块化」而非固定骨架 |
| 设置项层级 | 优秀做法 = 4 层：**全局样式（主题色/字号/字重/间距）→ 页面设置（页边距/纸张/gap）→ 区块级设置（标题/图标/是否显示 heading、keep together）→ 条目级（hidden 单条隐藏）** |
| 照片处理 | Reactive Resume 照片参数化最全（尺寸/圆角/边框/旋转/裁切 fit/shadow/aspectRatio/是否隐藏）——可直接吸收为「照片控件」；猫步只支持头像形状（方/圆） |
| PDF 导出 | 两派：**@react-pdf/renderer 库**（Reactive Resume、open-resume：文字可选中、ATS 友好、跨端一致）vs **浏览器打印 window.print()**（opresume、dnd-resume：CSS print 直接、零依赖但端不一致）。ResumeX 已用 html-to-image + jsPDF（截图式），**文字不可选中、ATS 不友好**——本文建议吸收「库渲染」理念，混排时退化为截图 |
| ATS 友好 | 纯文本单栏 + 网页安全字体 + 标准标题（markdown-resume / open-resume / opresume 三家殊途同归）——ATS 的核心是**文字层**，不是视觉 |
| 数据模型 | Reactive Resume 的 Zod schema 是最完整的参考：12 内置区块 + 13 可自定义区块类型 + 每区块统一「title/icon/columns/hidden/showHeading/keepTogether/startOnNewPage」+ styleRules（语义样式规则） |

## 1. 猫步简历 resume-design（Hacker233/resume-design，Vue3，3970 stars）—— 头部重点

**一句话定位**：国内最大的开源「在线简历制作」全家桶（前端 Vue3 + 后端 Nest.js + MongoDB），主打「海量模板 + 物料拖拽编辑」，并有积木式设计器（LegoDesigner）让用户自定义模板。

**URL**：https://github.com/Hacker233/resume-design

**调研事实**（均实证于仓库目录/源码，非记忆）：
- 技术栈：Vue3 + TypeScript + Vite + Element-plus + Pinia；后端 Nest.js + MongoDB + MinIO（README）。
- 模板挂载式组件结构（`src/template/index.ts`）：6 套模板命名只有 template1~template6（ID + NAME + previewUrl 图片），另有 `custom` 一套（自建模板/JSON 导入）。
- **物料（模块）体系**（`src/material/` 目录，19 个物料组件）：Avatar、BaseInfo（基础资料）、JobIntention（求职意向）、EduBackground（教育背景）、SkillSpecialties（技能特长）、CampusExperience（校园经历）、InternshipExperience（实习经验）、WorkExperience（工作经验）、ProjectExperience（项目经验）、Awards（所获奖项）、Hobbies（兴趣爱好）、SelfEvaluation（自我评价）、WorksDisplay（作品展示）、ResumeTitle、ResumeBackground、ModelTitle、Custom、Common、CommonCom——**每个模块是独立「积木」，可增删、拖拽排序、独立开关 show**。
- **每个模块有对应设置面板**（`src/options/` 目录 23 个 Options 组件，如 BaseInfoOptions / WorkExperienceOptions / GlobalStyleOptions…）：点选模块 → 右侧属性面板改该模块样式。
- **数据模型**（`src/schema/resume.ts` + `src/interface/model.ts`，描述性转述）：
  - 简历骨架：`ID / NAME / TITLE / LAYOUT（'classical' 传统单栏 | 'leftRight' 左右双栏 | 'custom'） / COMPONENTS（模块列表） / GLOBAL_STYLE`。
  - 每个模块（如 BaseInfo）字段：`model / show（是否显示） / title（栏目名） / iconfont（图标） / isShow（子字段级隐藏开关，如年龄/邮箱/头像各自可隐藏）/ LIST（条目数组）`。
  - **GLOBAL_STYLE**（`src/interface/globalStyle.ts` + `schema/resume.ts` 实测字段）：themeColor（主题色）、firstTitleFontSize（一级标题字号）、secondTitleFontSize、textFontSize、secondTitleColor、textFontColor、secondTitleWeight、textFontWeight、modelMarginTop、modelMarginBottom、leftWidth/rightWidth（左右布局宽度）、leftThemeColor/rightThemeColor（左右栏背景色）、resumeBackgroundCom。
  - **特色：单条模块级宽度/边距（mTop/mRight/mLeft/mBottom/pTop/...）都进了模型**（`ISTYLE` 接口），即「样式颗粒度到每条内容」。
- 布局模式实测（`src/views/onlinePreview/components/OnlineResume.vue`、`MainCenter.vue` 等）：`classical` 单栏（顶部简历标题 + 顺序模块）、`leftRight` 左右双栏（leftList / rightList 两条模块链，含 leftWidth/rightWidth 与左右栏主题色）、`custom`（JSON 导入/导出）。
- 导出能力（README）：超高清 PDF、图片、JSON、Markdown（README 明确列 PDF/JSON；Markdown 见页面简介）。
- 编辑器交互（README + 目录）：左侧「物料区」选模块 → 中央画布实时预览 → 右侧属性面板；可拖动排序；有「模板切换抽屉」（SwitchTemplateDrawer.vue）、「查看 JSON 抽屉」（ViewJsonDrawer.vue）、「下载弹窗」（DownloadDialog.vue）。

**值得吸收的点（4 条）**：

1. **吸收「模块 = 积木 + 每模块独立 show 开关 + 建议位置」的产品理念**
   - 怎么吸收：ResumeX 已有模块类型（SkillsModule/ContentModule），**增加每模块 `show` 开关与「拖拽排序」**；左侧编辑器加「添加模块」入口（下拉：教育背景/工作经历/项目/技能/荣誉/兴趣爱好/自我评价/自定义），把当前 35+ 模板的骨架「降维」成「通用骨架 + 可选模块」，避免每套模板字段差异导致维护爆炸。**原创实现**：模块目录用我们的 ResumeModule 类型，不做它的 iconfont/素材包。
2. **吸收「子字段级 isShow 隐藏」的细粒度控制**
   - 怎么吸收：基础资料模块里，年龄/地址/工作年限/邮箱/头像等**每个子字段可单独决定显示与否**（国内简历惯例：体制内要年龄政治面貌、互联网可不写）。**原创实现**：在 settings 中加 `fieldVisibility: Record<string, boolean>`，模板用 `var(--color-primary)` 体系渲染，不复制其 isShow 结构。
3. **吸收「全局样式一枚主题色 + 分级字号（一级/二级/正文）+"双栏可调左右宽与左右栏底色"」**
   - 怎么吸收：把本工具 theme.ts 的 12 色扩为「预设色板 + 自定义取色器」，字号分「栏目标题/二级/正文」三档 + 间距（模块上下 margin）做成滑杆；**双栏模板允许调 leftWidth（如 25%/30%/35%）**——比硬编码左右栏宽的模板更符合国内「信息多但要紧凑」需求。
4. **吸收「JSON 一键导出/导入 + 每模板可预览图 + 模板切换抽屉保留数据」**
   - 怎么吸收：ResumeX 已有 zustand persist，**做「导出简历 JSON / 导入 JSON（换设备/分享）/ 换模板不丢内容」三位一体**；模板切换改为抽屉面板带缩略图，切换时只换骨架与主题，不丢失用户已填字段。**原创实现**：用我们自己的 data schema 做迁移校验（版本号 + 字段映射），不做它的后端云存储。
5. **吸收「积木式自定义模板（LegoDesigner 理念）只借鉴方向，不在 MVP 实现」**
   - 怎么吸收：标记为「远期理念」——让用户自己拼布局是高级玩法，但其复杂度（任意排版渲染 PDF）与「35+ 成品模板」路线冲突；本工具保持「成品模板 + 可调设置」，积木化留给后续版本评估。

## 2. Reactive Resume（amruthpillai/reactive-resume，42k stars）—— 最流行的开源简历生成器

**一句话定位**：注重隐私（You own your data）的开源简历生成器，15 套宝可梦命名模板 + 客户端 PDF 生成 + 多语种，是「模板 × 设置」解耦设计的标杆。

**URL**：https://github.com/amruthpillai/reactive-resume

**调研事实**：
- 技术栈：TanStack Start（React 19 + Vite）+ TypeScript + PostgreSQL/Drizzle + Tailwind + Zustand；PDF 用 @react-pdf/renderer（README 明确 v5.1.0 起纯客户端、不再用浏览器打印/外部服务）。
- **模板命名**（`packages/schema/src/templates.ts` 实测 z.enum 15 个）：azurill、bronzor、chikorita、ditgar、ditto、gengar、glalie、kakuna、lapras、leafish、meowth、onyx、pikachu、rhyhorn、scizor。（设计理念：DESIGN.md 明确「宝可梦命名是刻意的品牌选择，让模板像可收集品而非 Template 1/Modern/Classic 泛化名」。）
- **模板目录**（`packages/pdf/src/templates/` 实测 15 个目录 + shared）：每模板 = Page 组件 + semantic.ts（语义清单）；shared 目录放 section 渲染、filtering、rtl、font 注册等公共逻辑。
- **PDF 机制**：@react-pdf/renderer 纯客户端（README）。仓库内还见 `packages/pdf/src/browser.tsx` / `server.tsx`（浏览器/服务端两入口）、semantic stylesheet（语义 CSS 自定义样式）、CJK 字体兜底链（AGENTS.md 提及），说明它处理了**中文/西文混排与字体注册**问题。
- **数据模型**（`packages/schema/src/resume/data.ts` 实测，描述性转述，这是全文含金量最高部分）：
  - 顶层：`picture / basics / summary / sections / customSections / metadata`。
  - **picture**（照片）：hidden、fit（cover/contain 裁切）、url、size（32–512pt）、rotation、aspectRatio（0.5–2.5）、borderRadius、borderColor、borderWidth、shadowColor、shadowWidth——**照片参数化最全的开源实现**。
  - **basics**：name、headline、email、phone、location、website（url+label）、customFields（自定义联络字段数组：icon/text/link）。
  - **12 个内置区块**（sections）：profiles、experience、education、projects、skills、languages、interests、awards、certifications、publications、volunteer、references + summary。
  - **13 种可自定义区块类型**（customSections，靠 discriminatedUnion type 区分），支持自定义标题/图标/条目。
  - **每一 block 统一元字段**：title、icon（Phosphor 图标名）、columns（跨 1–6 列）、hidden、showHeading、keepTogether（单页不拆分）、startOnNewPage（强制新页）——**这是「区块级 print CSS 属性」的完整抽象**。
  - **experience 支持多角色**：company + position + period + roles[]（每角色 position/period/description）——同一公司多段晋升的完整表达。
  - **skills**：name + proficiency（文本）+ level（0–5）+ keywords[] + keywordLayout（inline/list）+ layout（default/inline）。
  - **layout（布局）**：sidebarWidth（10–50%，默认 35）、pages[]（每页 main[] + sidebar[] 两个 section ID 数组 + fullWidth）——**多页、双栏、每页分栏都由数据驱动**。
  - **page（页设置）**：gapX/gapY（区块间隙）、marginX/marginY（页边距，默认 14/12）、format（a4/letter/free-form）、locale、hideLinkUnderline、hideIcons、hideSectionIcons。
  - **design**：level（hidden/circle/square/rectangle/rectangle-full/progress-bar/icon 六种技能等级形态）+ colors（primary/text/background 三色）。
  - **typography**：body + heading 两组（fontFamily/fontWeights/fontSize 6–24pt/lineHeight 0.5–4 倍）。
  - **styleRules**：语义样式规则（target 可全局/按区块类型/按区块 ID）+ slots（按语义槽位 section/heading/item/text/link/icon/level/richParagraph…单独调颜色/字号/边距）——**「不写 CSS、按语义槽位微调」的高级方案**。
  - metadata.notes：作者私有备注（不打印）。
- 隐私/本地化：自托管、无追踪、无广告、基础使用无需账号、One-click delete、支持 JSON Resume 导入（README + 仓库）。

**值得吸收的点（5 条）**：

1. **吸收「模板 = 骨架 + 布局数据 + 样式数据」全解耦，而非 15 个写死 HTML**
   - 怎么吸收：ResumeX 现状是 35+ 个独立模板组件。**引入「双栏/单栏骨架参数化」**：模板只声明「栅格（单栏/左右分栏、sidebarWidth）+ 模块默认样式」，数据里存「当前用户的 sections 顺序 + 左右栏分配」。**原创实现**：用我们的 TemplateId + ModuleType 体系做一个统一的 `TemplateChrome` 抽象层（每模板定制 header/配色细节），不照抄它的 layout.pages/main/sidebar 数组结构。
2. **吸收「区块级元字段」：showHeading / keepTogether / startOnNewPage / columns / hidden**
   - 怎么吸收：给 ResumeX 的每个 ResumeModule 加设置：`hidden（整块隐藏）、showHeading（留内容隐藏标题）、keepTogether（不跨页断块）、columns（1/2 列排版）`——这直接解决中文简历「教育背景要两列 / 技能要单列」的痛点。**原创实现**：在 `settings` 层做，导出时映射到 pdf 分页器。
3. **吸收「照片参数控件」：尺寸/圆角/边框/阴影/是否隐藏/裁切方式**
   - 怎么吸收：做「照片设置」弹层（尺寸滑杆、圆角滑杆、边框颜色粗细、裁切 cover/contain、旋转），国内证件照（一寸 295×413）可用「宽高比预设（1:1 / 1:1.4 / 1/2）」表达。**原创实现**：裁切用 canvas 预览 + 圆角用 CSS 变量（模板走 var(--photo-radius)），不复制其 shadowWidth（中性可留）。
4. **吸收「多角色经历、技能等级可拆」的字段设计，对齐国内「同一公司升职」场景**
   - 怎么吸收：工作经历条目支持「多职位 roles[]（每段职位+时间+职责）」；技能模块拆成「技能名 + 熟练度文本 + 关键词标签」三段，关键词提供 inline/list 两种排版。**原创实现**：熟练度控件用「文本 + 可选星级」而非强制等级轴。
5. **吸收「语义槽位微调样式」理念（styleRules 只借鉴方向）**
   - 怎么吸收：标注为「远期」——给高级用户「按区块类型微调栏目标题色/正文字号/链接色」，原则是**只允许安全属性（颜色/字号/字重/边距）**，并限定在模板已开放的语义槽位里，防止把简历改花。**原创实现**：设置面板用「预设 + 少量微调」而非任意 CSS 入口（我们无后端、无法校验任意 CSS 在 pdf 分页下的安全性）。

## 3. open-resume（xitanggg/open-resume，8.8k，TypeScript + Tailwind）

**一句话定位**：纯浏览器本地运行（无注册、数据不出浏览器）+ PDF 解析导入的开源简历生成器，主打「一模板 + 自动格式化 + ATS 友好」。

**URL**：https://github.com/xitanggg/open-resume

**调研事实**：
- 技术栈：TypeScript + React + Next.js 13 + Redux Toolkit + Tailwind；PDF 生成 **@react-pdf/renderer**，PDF 解析用 PDF.js（README）。
- **只有一套模板**：`src/app/components/Resume/ResumePDF/`（实测清单）：ResumePDFProfile、ResumePDFWorkExperience、ResumePDFEducation、ResumePDFProject、ResumePDFSkills、ResumePDFCustom + common（icon、错误抑制）+ styles.ts——即**单栏、段落式、无照片位**（README 强调「自动统一字体、字号、页边距、项目符号」）。
- **设置项**（`src/app/lib/redux/settingsSlice.ts` 实测，描述性转述）：`themeColor`（默认 #38bdf8 sky-400）、`fontFamily`（默认 Roboto）、`fontSize`（默认 11pt）、`documentSize`（Letter/A4）、`formToShow`（5 个表单各自显示开关：workExperiences/educations/projects/skills/custom）、**`formToHeading`（每个区块标题文案可自定义，默认 WORK EXPERIENCE 等大写英文，用户可改成中文）**、`formsOrder`（区块排序，up/down 交换）、`showBulletPoints`（每个区块项目符号开关）。
- **交互**（`Resume/index.tsx` 实测）：右侧 iframe 实时预览（ResumeIFrame + scale 缩放控制条 ResumeControlBar），左侧表单；有非英文 CSS 懒加载（FontsZh.tsx 等，说明对中文字体做了专门处理）。
- ATS 友好：README 明确「ATS 友好（Greenhouse/Lever 等）」，靠**统一尺寸/字体/项目符号 + 无照片/无图标**；PDF 层文字可选中。

**值得吸收的点（4 条）**：

1. **吸收「区块标题文案可自定义」**
   - 怎么吸收：ResumeX 每个模块标题允许用户改文案（默认为「工作经历/PROFESSIONAL EXPERIENCE」）——服务中英双语、服务「作品集/实习/项目」等场景，成本极低收益高。**原创实现**：标题变更存进 settings，**模板只负责渲染 var(--section-title) 而不写死标题字**。
2. **吸收「表单显示开关 + 区块排序 + 项目符号开关」三大交互即「最小版面控制权」**
   - 怎么吸收：编辑器左侧给「模块管理」：显示/隐藏、上下拖动排序、每模块「项目符号 on/off」（中文简历常去项目符号、用短横线）。**原创实现**：复用我们已有的模块拖拽（05 号文件已有设计），增减「项目符号开关」项。
3. **吸收「一模板极致 + 自动一致性」做「ATS 极简无彩模板」**
   - 怎么吸收：做一套「ATS 极简模板」= 单栏、无照片位默认无、无图标、黑白、标准标题、正文 10.5–11pt、**禁止用户调主题色（灰显）**——对标国内网申系统（不解析照片/图表），也回答 01 号文件的「ATS 友好」要求。**原创实现**：该模板设置面板里主题色控件禁用并提示「网申模板不可换色」。
4. **吸收「非英文（中文）字体懒加载 + iframe 预览隔离」的技术思路**
   - 怎么吸收：预览 iframe 隔离简历 CSS（我们预览和导出共用 DOM，可考虑 iframe 包一层避免编辑器样式污染）；中文/自定义字体注册做成 **按需加载**（只有选了该字体的用户才载入 woff2，避免首屏 12 套餐字体全拉）。**原创实现**：复用我们已有的字体方案，只吸收「按需 + 隔离」两个思想。

## 4. markdown-resume（junian/markdown-resume，ATS 友好向）

**一句话定位**：纯本地、PWA、离线可用的「用 Markdown 写 ATS 友好简历」的草根编辑器，无模板库、靠「克制排版 + 多格式导出」胜出。

**URL**：https://github.com/junian/markdown-resume

**调研事实**：
- 本地优先：无账号；数据（简历/图片/设置）存浏览器 IndexedDB（localForage）；Service Worker 供图；AGPL-3.0（README）。
- 编辑器：左 Monaco 代码编辑 + 右分页实时预览；支持 KaTeX 公式、Iconify 图标、自定义 CSS、自动保存、大小写校正、多简历管理/复制/导入/备份。
- **排版本质**：默认模板参考 CareerCup 简历模板——克制布局、网页安全字体、可读结构（README：restrained layout, web-safe fonts, readable content structure）。
- **导出**：PDF、Markdown、自包含 HTML、DOCX（A4 与 Letter）；HTML/DOCX 导出时图片转 base64 内嵌；分页有自动分页 + 类 LaTeX 的 `\\[10px]` 强制换行、`\newpage` 换页指令。
- **ATS 设计**（README 原意转述）：Markdown 纯文本源文 + 简洁布局 + 网页安全字体 →「对人好，对 ATS 也好」；提供 DOCX 兜底 ATS 解析。

**值得吸收的点（3 条）**：

1. **吸收「ATS = 文字可选中 + 标准结构 + 网页安全字体」的判断标准**（关键：不是视觉花哨与否）
   - 怎么吸收：给「ATS 极简模板」加规则：全文本直排、无图片（或图片用 alt）、不裁剪/不透明文字、栏目标题用「标准词」（教育背景/工作经历/项目经验）而非花体字；导出后**输出「文字可选中」校验**（在导出弹层里提示「本简历文字可选中，ATS 友好」）。**原创实现**：写一个导出自检器（逐字检查是否全部为文字层、无多列错位）。
2. **吸收「多格式导出兜底」：PDF 之外给 DOCX 兜底**
   - 怎么吸收：我们已有 Word 导出（exportDocx.ts）——在「ATS 极简模板」上把 DOM 渲染导出的 Word 作为推荐格式（网申系统常只收 PDF/Word），文案「网申建议用 Word 版」。**原创实现**：复用现有 exportDocx，仅加模板级「ATS 提示」。
3. **吸收「内容源轻量 + 排版指令极简」的克制哲学**
   - 怎么吸收：不做 Markdown 全功能编辑器（与表单化路线冲突），但吸收**「分页不要失控」理念**：提供「模块强制换页/不跨页拆分」两个分页开关（对应它的 \newpage / 自动分页），帮用户获得可控的一页纸。**原创实现**：分页开关映射到导出分页器，而非在正文里塞排版代码。

## 6. 模板布局思路总结（开源视角 + 国内适配）

### 6.1 单栏 vs 双栏比例

| 项目 | 骨架 | 双栏支持 |
|---|---|---|
| open-resume | 仅单栏（段落式） | 无 |
| markdown-resume | 单栏（Markdown 流式） | 无 |
| opresume | 单栏为主（外企单栏风） | 规划目录里有双栏、未确认 |
| 猫步简历 | `classical` 单栏 / `leftRight` 左右双栏 | 有，宽度可调 |
| Reactive Resume | 模板默认各异，但底层 layout.main/sidebar 支持任意模板双栏/多页 | **数据层全支持** |

**结论（针对中文）**：
- **单栏仍是主基调**（与 02 号文件实测国内商业站一致：双栏 <20%）。
- 双栏的正确姿态：**「左侧 ≤30% 浅色栏（个人信息/技能/证书）+ 右侧主经历」**，且**左栏宽度可调**（Reactive Resume sidebarWidth 10–50%、猫步 leftWidth）——国内用户需要「信息多但要一页」时天然想要双栏。
- 双栏是**布局参数而非独立模板**：模板组件应复用同一套 section 渲染，只暴露「单栏/双栏（左栏宽度/底色）」。以 02 号文件推荐清单为准：左栏浅底 #F5F5F5（而非满深色），色条贴纸边为点缀。

### 6.2 照片处理（开源实现 vs 国内惯例）

- Reactive Resume（最多维度）：尺寸/圆角/边框/阴影/旋转/裁切(cut cover·contain)/宽高比/是否隐藏——**技术上限**。
- 猫步：头像形状（avatarShape，圆/方）+ 是/否显示（isShow.avatar）。
- open-resume：无照片位（ATS 导向）。
- 国内惯例（01/02 号文件）：右上角一寸 25×35mm 方角证件照（或顶部居中照片带，校招模板），证件照大小按行业；互联网/外企技术岗可不放。
- **吸收方案**：照片控件做「**位置（右上/顶部居中/左栏顶）+ 形状（方圆）+ 尺寸三档（小/中/大）+ 隐藏**」四个维度即可，宽高比给「1:1 / 证件照 25:35 / 自由」三个预设；不吸收旋转/阴影（国内不需要、且会牺牲 ATS 可解析性）。

### 6.3 栏目标题做法

- **开源英文**：大写加粗 + 小图标（Phosphor icon 前缀，如 Reactive Resume 的 section.icon）+ 区分大小写英文（open-resume formToHeading 默认大写英文）。
- **开源中文**（猫步）：iconfont 图标 + 汉字标题，标题本身也在「模块」里（ModelTitle），可自定义。
- **国内商业站实测（02 号文件）**：加粗 + 下划线/细色横线；无图标占主导；标题色 = 主题色或深灰。
- **吸收方案**：栏目标题提供「**样式三选一**：下划细线 / 左侧色条 / 纯加粗（无装饰）」，图标默认**关**（ATS 极简模板强制纯文字）——把「标题是否有图标」做成每模块开关，而不是写死在模板里。

## 7. 设置项总结（字体/字号/间距/主题色怎么组织最好）

### 7.1 参考：开源的四层设置模型

| 层 | 代表实现 | 项目 |
|---|---|---|
| L1 全局 | themeColor + 一/二级/正文字号 + 字重 + 模块上下间距 | 猫步简历 GLOBAL_STYLE |
| L1' 设计 | colors(primary/text/background) + typography(body/heading) | Reactive Resume |
| L2 页面 | 页边距 marginX/marginY + 区块间距 gapX/gapY + 纸张格式 + 链接下划线/图标全局开关 | Reactive Resume pageSchema |
| L3 区块 | title/icon/columns/hidden/showHeading/keepTogether/startOnNewPage | Reactive Resume baseSectionSchema |
| L4 条目 | 单条 hidden、条目级字段 isShow | Reactive Resume（item hidden）+ 猫步（isShow）|
| L5 语义微调 | styleRules（按语义槽位微调颜色/字号/边距） | Reactive Resume（远期）|

### 7.2 哪些是「好」的（吸收），哪些别学

- **好**：主题色单枚 + 文字色 + 背景色三色结构（简单、够用）；字体族与字号分开调；页边距与区块间距分开；隐藏/去掉标题开关是「内容层面」控制，不污染样式。
- **好**：open-resume 的「每区块标题可改文案 + 显示/隐藏/排序/项目符号」四开关——把用户最关心的 4 个版面动作放最前面。
- **好**：猫步的「左右栏各自背景色 + 左右宽度」参数——双栏模板唯一必要参数对。
- **别学 A（过细）**：猫步 ISTYLE 的每条内容都能单独调 mTop/mRight/pLeft 等 → 会让用户把版面调乱，ResumeX 只开放「全局 + 区块两级」。
- **别学 B（过全**）：Reactive Resume styleRules 语义槽位有 14+ 槽位/20+ 属性 → MVP 用「预设主题色 + 12 色 + 少量微调」代替。
- **建议 ResumeX 最终设置面板**：
  1. 主题色（12 预设 + 自定义，模板级约束：ATS 模板禁用）
  2. 字体（每模板默认三选 1–3，可选「跟随系统」）
  3. 字号三档：栏目标题 14–16 / 二级标题 / 正文 10.5–12（滑杆 + 档位按钮）
  4. 行距（1.15–1.5）+ 模块间距（对应页边距按国内 15–25mm 档位：紧凑/标准/宽松）
  5. 页面：纸张 A4、偏窄边距可选
  6. 区块：显示/隐藏、标题文案、图标 on/off、项目符号 on/off、两列 on/off（部分模板）
  7. 照片：位置/形状/尺寸/隐藏
  8. 高级（可见于「高级」折叠区）：keepTogether、行级间距微调（限 ±2pt）

## 8. 导出机制总结（PDF 怎么做 + 文字可选中性）

| 项目 | 机制 | 文字层 | 优 | 劣 |
|---|---|---|---|---|
| Reactive Resume | @react-pdf/renderer（纯客户端） | 是（矢量文字） | 跨端一致、文字可选中、字体嵌入、RTL/连字 | 富文本能力有限（语义化处理）、学习成本 |
| open-resume | @react-pdf/renderer | 是 | 同上；且有中文字体专项处理 | 需字体内嵌（包体大） |
| 猫步简历 | 截图渲染（html-to-image/pdf 库）+ 高清 PDF | 不可选中（截图式） | 还原度高（所见即所得） | 文字不可选、文件大 |
| opresume | 浏览器原生 print()（window.print/打印对话框 Save as PDF） | 是 | 零依赖、简单、与预览同 DOM | 浏览器差异（边距/缩放）、Chrome 依赖、不跨端 |
| dnd-resume | 浏览器原生 print() | 是 | 同上 | 同上 |
| markdown-resume | 各自闭环（PDF/HTML/DOCX） | 是（HTML/DOCX） | 多格式兜底 | PDF 机制未公开细节 |

**ResumeX 现状与差距**：我们是 **html-to-image (toCanvas) + jsPDF 分页** → 截图式，**文字不可选中、对 ATS 不友好**（04 号文件已有讨论）。
- **吸收方向 1（推荐）**：**「库渲染优先」**——把「ATS 极简模板」与「基础单栏模板」的 PDF 走**程序化渲染**（新开一个小型 PDF 渲染层：标题/条目/文本，用 jsPDF text API 或 docx→pdf 思路；不复制 @react-pdf/renderer 代码），确保**矢量文字可选中**。
- **吸收方向 2（保底）**：截图式保留为「高保真」路径，用于复杂模板；导出菜单里**两个出口放一起**：「高清版（所见即所得） / 网申版（文字可选中）」。
- **吸收方向 3（简单出口）**：给「ATS 模板」额外提供**浏览器打印路径**（@media print 已有），用户可「另存为 PDF」——零成本覆盖最简单场景。
- 三条路径共用同一个「导出前自检」：输出前提示「当前模板是否 ATS 友好（文字可选中/单栏/无照片位/标准标题）」。

## 9. 明确界线（只吸收理念，绝不复制）

### 9.1 只吸收理念、必须原创实现的部分

| 理念 | 来源项目 | 我们怎么做（原创） |
|---|---|---|
| 「模块化 + 每模块独立 show」 | 猫步 | 用我们已有 ResumeModule 体系，新增 settings 级开关，不做 iconfont/素材组件包 |
| 「模板 = 骨架 × 布局参数 × 样式参数」解耦 | Reactive Resume | 我们每模板仍是独立 React 组件（保留35+模板的差异），但把「双栏/宽度/底色/栏目标题样式」抽为公共参数，数据用我们自己的 schema |
| 「宝可梦命名（模板可收集化）」 | Reactive Resume | **不采用模板名只做趣味**（中文工具用「校招通用/商务深蓝/ATS 极简」等描述性名称更可理解；趣味命名与中文求职场景不符） |
| 「ATS = 文字可选中 + 标准结构」 | open-resume/markdown-resume/opresume | 我们做「ATS 极简模板 + 文字可选中自检 + 双出口（矢量 PDF/浏览器打印）」 |
| 「本地优先（数据不出浏览器）」 | opresume / open-resume / dnd-resume | ResumeX 已是 localStorage 无后端；**吸收「无追踪/无广告/可自托管」理念**（指部署与隐私文案，不复制其代码） |
| 「多格式兜底（PDF + DOCX + JSON）」 | markdown-resume（DOCX）/ opresume（JSON）/ 猫步（JSON+MD） | 我们已有 Word 导出 + JSON 备份；补充「Word 版为网申推荐」文案与入口 |
| 「照片参数化控件」 | Reactive Resume | 只做位置/形状/尺寸/隐藏四个维度 + 3 个宽高比预设 |
| 「智能分页 + 页码悬浮 + 建议删除」 | opresume | 用我们已有分页计算逻辑（jsPDF 分页）给预览层反馈 |
| 「打码模式（分享隐私）」 | opresume | 渲染层 privacyBlur 开关，数据不动 |
| 「浏览器打印导出备用」 | dnd-resume | 仅对 ATS 模板开放 @media print 路径，不做默认 |

### 9.2 明确禁止（红线）

- **禁止复制**：任何模板组件的 JSX/Vue 写法、className、CSS 选择器、颜色常量、图标名、文案（如 README 宣传语、设置项中文标签）、宝可梦命名、JSON 字段名与 schema 结构（zod/interface 一律不抄，我们的数据结构用我们自己的字段）。
