# 02 竞品审美与模板分类（调研）

> 目标：描述**真实竞品页面长什么样**（布局/颜色/密度），用于确定 ResumeX 的模板审美基准与编辑器 chrome。
> 方法：全部站点用真实浏览器（Playwright）打开并截图/读取 DOM/采样缩略图像素颜色，非凭记忆。每条事实附 URL。
> 折算说明：缩略图颜色为像素聚类抽样（16 级量化后还原，±8 色阶误差），站点品牌色来自 getComputedStyle，两处来源分别标注。

---

## 0. 结论速览

| 问题 | 一句话结论 |
|---|---|
| 国内主流模板布局 | **绝对主流是单栏白底**，栏目标题用深色细线/下划线/左侧色条区分；双栏（左侧 25–30% 色块侧栏）是少数派，多用于"信息多"场景 |
| 模板颜色 | 全部以**黑/白/灰为底 + 单一种强调色**（蓝系居多，其次红/绿/深藏青）；多色渐变模板几乎只在"创意/个性"分类出现 |
| 照片 | 主流放右上角（小方照），校招模板尤盛；有"带证件照"独立分类 |
| 编辑器 chrome | **国内效率工具风**：左侧表单/Markdown 分栏 + 中央/右侧 A4 实时预览 + 顶部轻工具条；登录悬浮窗、会员横幅等营销元素缠身 |
| 推荐 8 套清单 | 见第 4 节，按默认清单执行，仅少量色值微调 |

- **一页 A4**："我强烈建议简历内容不要超过一页A4纸"；HR 初筛每份仅几十秒、行业默认惯例、展现信息提炼能力；仅学术研究类 CV 可多页。
- **两套整页版式**（原文附图）：左侧版式适合还没有主导/参与公司项目的职场新人；右侧版式适合有多个全职工作经验、或职位有硬性门槛（如编程语言、PMP/Agile 证书）者。
- **基本信息**：姓名、手机、邮箱、城市；**不要用 QQ 邮箱**；照片是否放取决于行业/职位要求与公司文化——"在美国、英国、加拿大等国家，简历一般是不放照片的"（即国内部分场景放）。
- **教育背景**：只写本科及以上，按学位从高到低，院校/专业用官方全名。
- **工作经历**：按时间从最近到最远排列。
- **内容格式**：通常为无序或有序列表以保持简洁美观。
- **具体写作要求**（非视觉）：技能证书按领域分类（"类别名称：xxxxx（熟练），xxxxx（基础）"）；语言类信息合并成一行；删除"综合能力优秀"这类宽泛表述；Office 基础操作不用写除非熟悉进阶功能（如 VBA）；工作内容三要点 = **量化、动词多样化体现主导程度、聚焦结果/产出**，避免过程细节和"协助/参与"等弱化词。

### 6.2 文中推荐工具（国内编辑器的审美参照）

- **超级简历（WonderCV）**：微信扫码登录、智能一页功能、免费模板、左侧评分与分板块评估、中文一键翻译英文（需校对）。
- **RxResume（自托管开源）**：界面极简，10+ 种模板，页间距/字体/行距/内容块可调，导出 JSON/PDF 或生成分享链接。
- **Talentcat CV Maker**：排版模板 + AI 助手（简历分析/面试辅导/职业规划），可导入已有 PDF/文本做检查。
- **注意**：文中**未规定**颜色数量、栏目标题样式、禁止图标/边框等视觉细则——视觉禁令以超级简历官方《简历排版设计指南》（01 号文件第 5 节，https://www.wondercv.com/blog/Ph58J6oZ.html）为准：**配色不超过 3 种、黑白灰基础 + 单色点缀、模块标题加粗**。

## 8. 竞品审美归纳（ResumeX 基准）

### 8.1 「安全通用模板」从头到脚的布局（实测 4 家）

**单栏模板（WonderCV / 木及 / 乔布 / 五百丁多数）：**
1. **头部**：姓名居中（或左上），姓名下 1 行个人信息（电话/邮箱/城市，图标或竖线分隔），**照片置于头部右上角**（小方照，WonderCV 校招为顶部居中蓝带照片区）。
2. **栏目标题**：左对齐（偶居中），**加粗 + 下方细下划线/浅色横线**；字体为无衬线（雅黑/思源黑体）。
3. **正文**：单栏，上下两端贴边距，密度中高（10.5–12pt、行距 1.15–1.35、段间距小），经历用编号/项目符号。
4. **配色**：白底黑字 + **唯一强调色**（多为蓝 #2479BA/#4888F8/深蓝 #34495E，少数红 #B85858 / 绿 #0088ED）。
5. **无侧栏**（多数）；"双栏"仅出现在五百丁少数模板/木及"两栏"分类（左侧 25–30% 深蓝满色栏，右白底），**满色侧栏比浅底侧栏更常见**。

**双栏模板（五百丁 / 木及少量）：**
1. 左侧 25–30% 满深蓝（#281868 / #2828C8 / #486888）或深灰（#46505A 附近），照片在左栏顶部居中。
2. 右侧白底，主经历在上，技能/证书/自我评价在左栏下方。
3. 双栏模板在竞品中**占比 < 20%**，且集中在"信息多、一页"场景（五百丁/木及）、"创意/个性"分类（五百丁深色风）。

### 8.2 竞品实际用色速查表（实测）

|---|---|---|

| 五百丁 500d.me | **#00C091**（绿，getComputedStyle）、深灰 #46505A | 深藏青 #281868 / 宝蓝 #2828C8 / 亮蓝 #5878F8 / 橙黄 #F8C848 |
| 木及简历 | **紫 #7C5CFC 系**（CTA，截图目测） | 红 #B85858、深蓝 #486888、黑 #212121、深绿 #46826E |

**关键规律：** 所有竞品的模板在"安全通用"定位上都是**黑白 + 一种蓝**为基础；站点品牌色五花八门（橙/绿/紫/青），但不进入模板本身——模板与营销页是两套配色。

### 8.3 编辑器 chrome（国内效率工具 vs 欧美 SaaS）

**国内效率工具（实测木及 / 幻主 / 五百丁向导）：**
- **左侧 = 内容输入**：Markdown 编辑窗（木及）或结构化模块列表拖拽（幻主：基本信息/求职意向/教育背景/…）；右侧 = A4 实时预览（灰底画布 + 白纸，页码 1/2）。
- **顶栏 = 轻工具**："文件/编辑模式/选择主题/插件列表"（木及）+ 预览/下载/打印/更多（幻主）+ **智能一页开关**（两个站都有）→ 说明"一页"是国内编辑器的硬约束。
- **强转化元素**：试用横幅（灰底提示"无法保存简历和导出 PDF"）+ 紫色渐变"去登录"+ 右上"升级会员"（木及/幻主均确认）。
- **与欧美 SaaS 差异**：欧美（Canva/Flowcv 等）是**左侧全局导航抽屉 + 中央画布 + 顶部带状面板**、无强制登录；国内更接近 **表单式左右分栏 + 强引导转化**，且每个模板自带的"模块管理"极为显眼。
