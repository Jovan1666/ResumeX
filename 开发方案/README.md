# ResumeX 重建开发方案（交给执行智能体）

本目录是给**另一个执行智能体**用的完整任务包，不是半成品调研笔记。

| 文件 | 用途 |
|---|---|
| [00-执行总提示词.md](./00-执行总提示词.md) | **复制这一份作为执行智能体的第一条用户消息** |
| [01-现状审计与问题清单.md](./01-现状审计与问题清单.md) | 已核实的 bug / 畸形模板 / 桌面端缺口，禁止再从零猜 |
| [02-产品规格.md](./02-产品规格.md) | 产品决策、数据模型、模板政策、导出、自动更新、验收 |
| [03-实现计划.md](./03-实现计划.md) | 分阶段文件级实现顺序 |
| [04-子智能体任务卡.md](./04-子智能体任务卡.md) | 执行智能体必须开启的调研/审查子智能体，搜什么、写到哪 |
| [05-视觉自审清单.md](./05-视觉自审清单.md) | 视觉模型必须过的红线；看起来「奇怪/山寨/不正经」就打回 |

**交给执行智能体：** 把 `00-执行总提示词.md` **全文**作为第一条用户消息。若环境支持附件，同时附上 `02` `03` `04` `05`。执行智能体必须先开 6 个调研子智能体，再改代码。

冲突时以 `00` > `02` > `03` 为准，不要跟过时的根目录 `AGENTS.md`（仍写 BrowserRouter / 35 套 / localStorage）。
